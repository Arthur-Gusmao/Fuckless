## git

The version control system used by the whole world.

git tracks changes to files in a local repository, with history, branching, and merging, all offline and all yours.

### Local by default

git works entirely on your disk.

Every clone is a full backup of history; there is no central server you depend on to commit or browse.

### Files, not a database

git stores snapshots of your tree in `.git`, addressable by content.

The model is simple enough to explain in a lecture, which is why it outlived everything around it.

### The Unix habit

git is a set of small commands that compose: `git add`, `git commit`, `git diff`, `git log`.

It scripts cleanly, and it is what pass uses under the hood for versioned passwords.

### Freedom

git is free software that respects the user: no account, no lock-in, no cloud.

Your history lives on your machine, and you decide where it goes.
