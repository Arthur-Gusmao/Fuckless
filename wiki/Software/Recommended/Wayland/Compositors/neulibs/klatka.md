## klatka

A kiosk-style compositor for neuswc.

klatka has a single purpose: run one application fullscreen.

That narrow scope lets it shed almost everything a general-purpose compositor carries. No window management to speak of, no layouts, no decorations.

### A single purpose

Kiosk compositors exist for one reason, and klatka commits to it fully.

Whether the application is a display, a panel, or a dedicated tool, klatka puts it on the screen and stays out of the way.

### Minimal by omission

The power of klatka is in what it omits.

Because there are no windows to tile, float, or decorate, there is no code for any of that. Small, predictable, and exactly what the job needs.
