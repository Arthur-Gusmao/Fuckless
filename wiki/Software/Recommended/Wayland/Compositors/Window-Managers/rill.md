## rill

A minimalist scrolling window manager for river, written in Zig.

rill arranges windows in a single scrollable line instead of a grid.

### Scrolling layout

Windows are laid out in a row that scrolls under keyboard control.

Focus and the viewport move together, a simpler model than nested tiling.

### Simple animation

A single subtle animation smooths the scroll.

It is the only ornament, and it is optional.

### Minimalist

rill does one thing with the least code that does it.

For users who want a layout that is easy to reason about, it is a strong choice.
