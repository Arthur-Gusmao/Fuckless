## anvl

A minimal tiling window manager for river, written in C.

anvl is inspired by dwm and by tinyrwm, keeping the dynamic tiling model while staying small enough to read and modify.

### dwm for river

Like dwm, anvl arranges windows automatically in a tiled layout with a master area.

The dynamic tiling habits of dwm users carry over directly.

### Small C codebase

anvl is written in plain C, in the style of the suckless tools.

The codebase is small, so the whole window manager can be understood at once.

### A foundation to build on

Because anvl follows the tinyrwm structure, it is easy to modify or extend.

It is a good base for a user who wants to own their window manager instead of renting one.
