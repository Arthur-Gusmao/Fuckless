## rijan

A small dynamic tiling window manager for river, written in about 600 lines of Janet.

rijan is by Isaac Freund, the author of river itself, and it proves how small a river window manager can be.

### 600 lines

At roughly 600 lines, rijan is one of the smallest window managers that still does real work.

The whole program fits in the head of one person, and there is nowhere for bloat to hide.

### Written in Janet

Janet is a small functional language that compiles to a single binary.

It keeps the window manager readable while letting the author express layout logic tersely.

### The right size

rijan is a demonstration that a window manager does not need a framework, a build system, or a large team.

It is also a fine choice to run, and an even better one to read.
