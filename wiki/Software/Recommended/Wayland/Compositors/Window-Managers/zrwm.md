## zrwm

A dynamic tiling window manager for river, written in C.

zrwm is configured through a command-line tool instead of a config file.

### Configured from the CLI

Settings are changed by running a command, not by editing a file and restarting.

The configuration is explicit and scriptable, and there is nothing to recompile.

### Dynamic tiling

Windows are arranged in a tiled layout with a master area, operated from the keyboard.

### Small C codebase

zrwm is plain C in the spirit of the dwm family: small, readable, and hackable.
