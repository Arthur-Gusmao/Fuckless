## crofflewm

A static tiling window manager for river, written in Go.

crofflewm abandons automatic layout for explicit control over the grid.

### Static tiling

Windows are placed where you put them and stay there.

Unlike dynamic tiling, the layout never changes under you: what you arrange is what you get.

### Written in Go

Go keeps the window manager simple to build and read, with a single static binary as the result.

### Minimal

crofflewm does the one job of placing windows and leaves the rest to the user.
