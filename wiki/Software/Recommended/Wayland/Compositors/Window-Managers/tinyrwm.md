## tinyrwm

The official river window manager examples, by the river author.

tinyrwm is not one program but a set of tiny window managers, each written in a different language, that implement the `river-window-management-v1` protocol.

### A starting point

The repository documents how to write a river window manager in C, and mirrors the design in other languages.

It is the canonical reference for anyone writing their own window manager, and the smallest working example that can be read in full.

### The right size

Each implementation is small enough to read, modify, and rebuild.

For a river user, tinyrwm is a lesson in how little code a window manager really needs.
