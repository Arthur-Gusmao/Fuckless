## wbg

A minimal wallpaper utility for Wayland.

wbg sets a wallpaper image on the background of each output, using the `zwlr-layer-shell` protocol.

### As small as it gets

wbg is a single C file's worth of program, the smallest way to set a wallpaper on Wayland.

There is no slideshow engine, no configuration daemon, and no feature list to read.

### Set and forget

It sets the wallpaper, possibly scaled or centered, and exits.

### Written in C

wbg is from the same small, correct C tradition as the rest of this wiki.

It works on every compositor recommended here.
