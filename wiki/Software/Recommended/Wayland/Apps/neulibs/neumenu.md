## neumenu

A dmenu fork for Wayland, built on neuwld.

neumenu brings the dmenu interaction model to the neulibs ecosystem, with better font rendering through neuwld.

### dmenu, updated

The dmenu behavior is kept: type to filter, select, print the result.

The update replaces the old rendering with neuwld, so the menu looks right on a neulibs desktop.

### Composable

Like dmenu, neumenu reads from stdin and writes to stdout.

It composes with everything in the Unix tradition.

### The launcher of the ecosystem

On a neuswc desktop, neumenu is the launcher that belongs.

It is the same role mew plays for the wider Wayland tools in this wiki.
