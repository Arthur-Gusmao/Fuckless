## chum

An interactive region picker.

chum lets the user select a region of the screen, for screenshotting and similar tools.

### The selection tool of the ecosystem

chum is the region selection tool of the neulibs ecosystem.

It is required for `swcsnap region`, the region screenshot of the neuswc stack.

### Interaction only

chum only returns the selected geometry.

What you do with it is up to the next program in the pipe.

### Minimal

A small program that does selection and nothing else.

It fits the pattern this wiki recommends everywhere else.
