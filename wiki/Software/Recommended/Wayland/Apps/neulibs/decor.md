## decor

Window decoration themes for neuswc.

decor is a collection of window decoration themes for neuswc-based compositors, along with tools to convert artwork.

### A collection, not a daemon

decor provides the artwork and the `png2swc` conversion script for window borders.

The compositor draws the decorations; decor just supplies the images.

### Simple integration

Each theme includes per-theme width information, so compositors know how much space the decoration needs.

No theme engine, no manager daemon.

### The finishing touch

For users who want window borders on a neuswc desktop, decor is the smallest way to get them.
