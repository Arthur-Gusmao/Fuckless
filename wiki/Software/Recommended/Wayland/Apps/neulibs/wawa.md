## wawa

A minimal wallpaper setter for the layer-shell protocol.

wawa displays an image as the background, drawn on a layer-shell layer.

### The neulibs wallpaper

wawa is the wallpaper tool of the neulibs ecosystem, in the same role wbg plays for the wider Wayland tools in this wiki.

### One job

wawa sets the background image and exits.

No slideshow, no configuration daemon.

### Small and native

A tiny program using the layer-shell protocol.

It is the minimal answer to a plain question: put this picture behind my windows.
