## swiv

An image viewer built on neuwld.

swiv displays images using the neuwld drawing library.

### Minimal viewer

swiv shows an image and little else.

No library, no file manager, no thumbnails.

### Part of the neulibs stack

Like the other programs in this section, swiv renders through neuwld.

It fits naturally into a neuswc-based desktop.

### Small and single-purpose

A viewer that views, in the spirit of this wiki.

It is the image tool of the neulibs ecosystem.
