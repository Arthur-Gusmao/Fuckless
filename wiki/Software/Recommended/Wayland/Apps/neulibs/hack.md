## hack

A text editor built on neuwld.

hack is a small text editor that renders through the neuwld drawing library.

### Small editor, small stack

hack stays in the tradition of the minimalist editors in this wiki: one program, one window, the essentials.

Its rendering uses the same neuwld library as the rest of the neulibs ecosystem.

### Keyboard-first

Editing is keyboard-driven, with no toolbar and no menus.

### A neulibs editor

hack pairs with hst and the neuswc compositors.

It is the editor of a desktop where every component shares one small foundation.
