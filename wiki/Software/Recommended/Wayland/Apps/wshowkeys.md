## wshowkeys

Displays the keys being pressed on the screen.

wshowkeys shows a small overlay of the current key combinations, for screen recordings and presentations.

### A presentation tool

When recording a screen or teaching from a terminal, it is useful for the viewer to see the keys being pressed.

wshowkeys draws that overlay natively, using the layer-shell protocol.

### Minimal overlay

It shows only the current key combination and fades it out.

There is no settings menu; the behavior is the behavior.
