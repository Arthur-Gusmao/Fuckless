## emptty

A simple CLI-based display manager.

emptty is a display manager that lives entirely on the TTY: it prints a login prompt in the terminal and starts your session when you authenticate.

### No GUI, no desktop environment

emptty has no graphical greeter, no themes, no animation.

It is a login prompt, a config file, and a session launcher.

### Small C

Written in C with a single small configuration file.

It is the minimal way to boot into a compositor without typing commands by hand.

### TTY-first

Works on the console, in the tradition of the old getty login.

It is the anti-GDM, like everything else in this Login section.
