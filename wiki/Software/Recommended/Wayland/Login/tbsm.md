## tbsm

A TUI session manager written in pure bash.

tbsm shows a text menu of sessions in the TTY and launches the one you pick.

### The smallest login manager

tbsm is a single bash script.

There is no compiled binary, no configuration language, and nothing to install beyond the script itself.

### Session chooser

It lists the available desktop sessions and starts the selected one.

### Scriptable

Because it is bash, it is trivially readable and trivially modified.

It is the login manager for users who want the whole thing in their head.
