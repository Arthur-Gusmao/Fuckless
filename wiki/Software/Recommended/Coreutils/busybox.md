## busybox

The Swiss Army Knife of embedded Linux.

busybox combines hundreds of common Unix utilities into a single small executable.

### One binary, everything

`ls`, `cp`, `sed`, `awk`, `sh`, `vi`, and hundreds more, all selected by the first argument.

### Built for tiny systems

busybox is designed for embedded Linux where GNU coreutils cannot fit.

That discipline keeps the code small and the scope tight.

### The pragmatic base

It is a single static binary that replaces a full userspace.

The standard choice when you need a complete base system with minimum size.
