## sbase

The suckless base utilities.

sbase is a collection of basic Unix commands, each implemented as a tiny standalone program.

### The small coreutils

Commands like `cat`, `ls`, `cp`, `grep`, and `sed` are rewritten from scratch, one file each, with no GNU baggage.

Each tool does its one job and stays readable.

### Do one thing well

sbase is the Unix philosophy taken literally: dozens of small programs, each of which you can read in full.

No options soup, no internationalization machinery, no bloat.

### From suckless

sbase is part of the suckless ecosystem that inspires this wiki.

It is the honest replacement for a pile of gigantic coreutils.
