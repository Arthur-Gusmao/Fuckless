## Rover

Rover is a lightweight terminal file manager designed around simplicity, speed, and keyboard-driven navigation. It provides the features needed for everyday file management while remaining small and easy to understand.

Rover follows the Unix philosophy of doing one job well. Rather than replacing the shell, it complements it by making common file operations faster and more convenient. It avoids unnecessary complexity and focuses on responsiveness and ease of use.

Compared to more feature-rich terminal file managers, Rover maintains a balance between functionality and minimalism, making it well suited for users who spend most of their time in the terminal.

### Fast to start, fast to use

Rover starts in an instant and responds immediately.

It does not spend time parsing a heavy configuration, loading a runtime, or maintaining a preview cache. The interface gets out of the way so the user can work.

### Keyboard-driven

Navigation is built around the keyboard.

Moving between directories, opening files, and performing operations are all a keypress away, which keeps the hands where they belong and makes repeated tasks feel effortless.

### No script to learn

The tool stays within the scope of file management.

It does not reinvent a scripting language, a plugin system, or a terminal multiplexer. What you see is what you get, and what you get is easy to understand.

### A complement to the shell

Rover handles what a shell is awkward at: browsing and picking files visually.

For everything else, the shell remains the tool of choice. Each does what it does best, and neither tries to absorb the other.
