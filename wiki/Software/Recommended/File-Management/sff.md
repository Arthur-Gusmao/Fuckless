## sff

sff is a lightweight terminal file manager built around speed, simplicity, and efficient keyboard navigation. It provides a clean interface for browsing and managing files while keeping the implementation small and easy to understand.

sff aims to provide a practical file management experience without unnecessary complexity. It follows the Unix philosophy by remaining focused on a single task and working well alongside standard command-line utilities.

### Lightweight by design

sff keeps its footprint small.

There is no runtime to start, no large dependency tree to install, and no background services to manage. A small program is also a predictable one.

### Keyboard navigation

Browsing is driven by the keyboard.

Movement, selection, and operations are quick and repeatable, making everyday file management faster than typing out commands by hand while keeping the user in control.

### Readable codebase

The implementation stays small enough to follow.

That makes sff easy to understand, easy to modify, and easy to trust. The source tells the whole story without a thick manual.

### Unix-compatible

sff does not hide the system behind an abstraction.

It composes with standard command-line utilities, letting each tool do what it does best instead of reinventing them in one large program.
