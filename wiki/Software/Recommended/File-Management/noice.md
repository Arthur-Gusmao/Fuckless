## Noice

Noice is a minimalist terminal file manager focused on fast directory navigation and essential file operations. Its small codebase and straightforward interface make it easy to understand, modify, and integrate into Unix-like workflows.

Noice embraces the Unix philosophy by providing only the essentials. It expects users to rely on standard command-line tools for advanced operations, making it an excellent companion to the shell rather than a replacement.

### A kernel, not a kitchen sink

Noice is deliberately small.

It navigates directories and performs the basic file operations needed to get work done. Everything else is delegated to standard tools, so the user stays in control of how files are actually handled.

### Keyboard-first

The interface is built around fast, keyboard-driven navigation.

Move through directories, open files, and operate on them without leaving the keyboard. The less time spent reaching for a mouse, the faster the workflow.

### Small enough to own

Noice's codebase is small enough to read in an afternoon.

That makes it hackable in the truest sense: understanding the whole program is realistic, and extending it is a matter of editing code, not wrestling with a plugin architecture.

### The shell stays in charge

Noice does not try to replace the shell.

It is a front end for the file operations the shell does well, leaving the real power where it belongs. This separation of concerns is what keeps both tools simple.
