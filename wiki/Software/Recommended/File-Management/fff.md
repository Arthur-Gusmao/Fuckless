## fff

Fucking Fast File-Manager.

fff is a file manager written as a single bash script, fast enough to replace a window for the job.

### A script, not an application

fff is one bash file with no dependencies and no configuration language.

It is the smallest file manager that is still a file manager.

### Keyboard-driven

Navigate with the keyboard, preview files in the terminal, and run commands on them.

### Fast

Because it is a script, it starts instantly and does exactly what a shell session does.

It is the minimal middle ground between bare commands and a graphical file manager.
