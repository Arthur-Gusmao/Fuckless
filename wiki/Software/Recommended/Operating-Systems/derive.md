## dérive

A simple and independent x86-64 Linux based on musl libc and busybox.

dérive is built almost entirely without GNU software, with everything statically linked.

### musl and busybox

musl for libc, busybox for core utilities, and a simple shell-based init.

### Almost 100% GNU free

Only what is strictly needed remains; the rest is replaced by smaller, readable software.

### A fully independent stack

Its own ports system with a corresponding binary repo, and a desktop stack from the wayland.fyi ecosystem.

### Everything static

Every binary is statically linked: no shared library hell.

An unfinished but honest operating situation, install at your own risk.
