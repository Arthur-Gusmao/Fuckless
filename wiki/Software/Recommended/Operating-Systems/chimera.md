## Chimera

A modern Linux built from scratch, without GNU.

Chimera combines the Linux kernel with a FreeBSD userland, musl libc, and the LLVM/Clang toolchain.

### No GNU, no systemd

Core tools come from the FreeBSD tree, the compiler is Clang, and the service manager is dinit.

### A coherent stack

musl libc, apk package manager, and dinit for both system and user services, all developed together.

### Correctness first

A small team, a rolling release, and a focus on simplicity without giving up features.

The boldest experiment in the non-GNU Linux space.
