## Source Mage

A source-based GNU/Linux distribution.

Source Mage builds every package from source, so nothing you did not choose gets installed.

### Everything from source

Packages are compiled from source using `cast` and the `sorcery` package manager.

### Grimoires of spells

Recipes live in grimoires, each spell describing exactly how to build the software.

### Bootstrap from nothing

The toolchain is built by hand first; from there the whole system grows.

No binary package bloat, no systemd, no surprises.

A serious distro for people who want to control every byte.
