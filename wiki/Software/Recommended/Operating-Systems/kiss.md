## KISS

A tiny Linux distribution built from scratch.

KISS is a source-based Linux that builds everything from source and stays readable.

### From scratch

The base is built from the ground up on musl libc, not derived from another distribution.

### A 1000-line package manager

The KISS package manager is a single small shell script you can read in full.

### No systemd, no bloat

Simple init scripts, minimal base, and the whole system assembled from source.

Now in maintenance mode, it remains the clearest statement of the minimal-distro philosophy.
