## kilo

A text editor in less than 1000 lines of C.

kilo was written by Salvatore Sanfilippo as a demonstration of what a text editor really needs, and it remains a fully usable editor.

### One thousand lines

The whole editor fits in a single C file under a thousand lines.

There is no configuration, no plugin system, no feature list. Everything about it can be held in one person's head.

### The honest editor

kilo keeps the essentials: open a file, edit it, search, save.

Its code is so clear that it has been used to teach editor design.

### A foundation

For users who want their editor to be their own, kilo is the perfect starting point.

It is ed and vi's philosophical sibling, modernized.
