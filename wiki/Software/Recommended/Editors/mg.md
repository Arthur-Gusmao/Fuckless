## mg

A small, fast Emacs-like editor.

mg is the micro Emacs maintained by the OpenBSD project. It is public domain, portable, and compatible enough with GNU Emacs that you never need to learn a second flavor.

### Emacs without the weight

mg is for people who cannot or will not run GNU Emacs.

It keeps the Emacs editing model and keybindings while staying small enough to read, audit, and port. No daemon, no package system, no Lisp engine.

### OpenBSD's editor

Maintained in the OpenBSD base system, where it must stay small and correct.

It is the base system's editor, so it carries the discipline of code that ships with an operating system.

### Public domain C

Small, portable, and free in the strongest sense.

No configuration language and no extension framework; the trade-off is a fixed, predictable editor that behaves the same everywhere.
