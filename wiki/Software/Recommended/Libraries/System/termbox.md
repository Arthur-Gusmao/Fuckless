## termbox

The original minimal terminal I/O library for TUIs.

termbox is a simple, clean ncurses alternative for building terminal pseudo-GUIs.

### Simple and clean

termbox provides the essentials of terminal interaction without the weight of ncurses.

Drawing cells and reading keys is all it does, and it does it well.

### The ancestor of termbox2

termbox2 is the successor, keeping the simple API while adding stricter error handling and built-in terminal support.

This page documents the original, which remains a clean example of a minimal TUI library.

### A teaching library

Small enough to read in full.

Many projects built on it, and its ideas survive in termbox2.
