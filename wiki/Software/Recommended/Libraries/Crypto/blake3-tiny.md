## blake3-tiny

A minimal public-domain implementation of BLAKE3.

blake3-tiny is Michael Forney's small implementation of the BLAKE3 hash function, with no dependencies and no build system beyond a Makefile.

### One file, one purpose

A single C file implements the hash.

The project exists as a small, reusable component rather than a wrapper around a larger project.

### Public domain

No license restrictions to worry about.

The code is free to copy into any program, which is how a hash library should behave.

### Fits the minimal stack

Like the rest of Michael Forney's software, it is C, simple, and portable.

Small enough to drop into any codebase without ceremony.
